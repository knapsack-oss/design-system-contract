# Security

This repository contains a specification, JSON Schemas, examples, and a small test suite. It runs no
service. A security issue here most likely means a schema that accepts something it should reject
in a way that could mislead a tool relying on it, or a problem in the test tooling's dependencies.

## Reporting a vulnerability

Please report it privately, not in a public issue, using GitHub's private vulnerability reporting:
the repository's **Security** tab, then **Report a vulnerability**.

Include what you found, how to reproduce it, and which version or commit it affects. We'll
acknowledge the report and keep you informed as we look into it.

Guidance: [Privately reporting a security vulnerability](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing/privately-reporting-a-security-vulnerability).
